# بازارنگر | تحلیل سهام آمریکا

داشبورد محلی فارسی برای تحلیل تکنیکال و فاندامنتال سهام/ETF آمریکا، فشار خرید/فروش تخمینی و محاسبهٔ اندازه موقعیت و سطوح ریسک. این پروژه **فقط تحلیل می‌کند و هیچ سفارشی ارسال نمی‌کند**.

## اجرا در Windows

نیاز به Node.js نسخه ۱۸ یا جدیدتر دارد؛ وابستگی npm اضافه‌ای لازم نیست.

```bat
cd C:\Users\hp\trading_platform2
set FINNHUB_API_KEY=توکن_شخصی_شما
npm start
```

برای اجرای حالت دمو بدون توکن، خط `set FINNHUB_API_KEY=...` را حذف کن و در مرورگر `http://localhost:3000` را باز کن. کلید Finnhub فقط به‌صورت متغیر محیطی سرور خوانده می‌شود؛ هرگز آن را در UI، کد، GitHub یا گفتگو وارد نکن. سطح دسترسی/محدودیت API به حساب Finnhub بستگی دارد.

## قابلیت‌ها

- نماد دلخواه سهام/ETF آمریکا (برای نمونه AAPL، MSFT، NVDA، SPY، QQQ)، بازه‌های ۵/۱۵/۳۰ دقیقه، یک ساعت و روزانه.
- تحلیل تکنیکال: EMA ۱۲/۲۶، MACD، RSI، ATR و حمایت/مقاومت تقریبی.
- فشار خرید و فروش تخمینی با حجم و موقعیت بسته‌شدن کندل. این داده جایگزین تیک، order book یا جریان سفارش واقعی نیست.
- فاندامنتال (ارزش بازار، P/E، EPS، رشد درآمد، ROE، بدهی به حقوق صاحبان سهام) و تیترهای شرکتی از Finnhub، در صورت تنظیم API key.
- سنجش کلیدواژه‌ای ساده برای تیترهای خبر؛ این مدل درک معنایی یا تحلیل فارسی ندارد.
- تخمین جهت/قدرت اکتشافی، قیمت مرجع، حد ضرر ATR، هدف ۲R، تعداد سهم پیشنهادی بر اساس ریسک و سرمایهٔ فرضی.
- ساعت بازار آمریکا بر مبنای America/New_York، روزهای دوشنبه تا جمعه و سشن اصلی ۹:۳۰ تا ۱۶:۰۰؛ تعطیلات رسمی بورس لحاظ نشده‌اند.
- حالت دمو برای تست رابط و محاسبات. همهٔ قیمت‌ها و حجم‌های این حالت مصنوعی هستند و اطلاعات بنیادی/خبر ساختگی تولید نمی‌شود.

## اجزا

- `src/analysis.js`: اندیکاتورها، امتیازدهی، pressure proxy، حدها و ساعت بازار.
- `src/providers.js`: آداپتر Demo و Finnhub برای کندل/قیمت/بنیادی/خبر.
- `server.js`: API محلی؛ کلید Finnhub سمت سرور خوانده می‌شود.
- `public/`: رابط کاربری فارسی RTL.

## محدودیت و ریسک

این نرم‌افزار توصیهٔ سرمایه‌گذاری نیست و برای معاملهٔ خودکار/اجرای سفارش ساخته نشده است. نقطه ورود، امتیاز جهت‌دار، سهم پیشنهادی و حدها فقط برآوردند. فشار خریدوفروش از OHLCV تقریب زده می‌شود؛ اثر اسپرد، کارمزد، لغزش، نوسان‌های خبر، نقدشوندگی لحظه‌ای و قطع داده لحاظ نشده است. نشست و تعطیلات بازار به‌طور تقریبی محاسبه می‌شوند. API رایگان ممکن است تأخیر یا محدودیت داشته باشد. تنظیم ریسک، نمایش سفارش واقعی یا تضمین حفظ زیان نیست.
