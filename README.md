# بازارنگر | تحلیل و بک‌تست رمزارز

پروژهٔ محلی فارسی برای BTC و ۱۰ جفت USDT برتر بر اساس حجم ۲۴ساعتهٔ Binance. موتور سیگنال، تحلیل و بک‌تست دارد؛ معاملهٔ صرافی انجام نمی‌دهد. اجرای موقعیت مجازی Paper اختیاری است.

## اجرا در Windows

Node.js نسخهٔ ۱۸ یا جدیدتر را نصب کن. در CMD:

```bat
cd C:\Users\hp\trading_platform2
npm start
```

مرورگر: `http://localhost:3000`. برای دریافت Binance اینترنت لازم است؛ Binance و CoinGecko از APIهای عمومی استفاده می‌شوند. حالت Demo فقط دادهٔ ساختگی برای بررسی رابط است.

## زمان ایران و بازشدن بازار آمریکا

بازار سهام آمریکا در ۰۹:۳۰ نیویورک باز می‌شود. برنامه پیش‌فرض همین لحظه را با DST به Tehran تبدیل می‌کند: در ۱۷ اکتبر ۲۰۲۶ معادل ۱۷:۰۰ تهران است، و بعد از پایان DST معمولاً ۱۸:۰۰ تهران می‌شود. **این ۱۵:۳۰ تهران نیست.** داشبورد زمان دقیق گشایش بعدی را نشان می‌دهد و اجازه می‌دهد زمان ثابت دلخواه ایران هم تنظیم شود. رمزارزها ۲۴/۷ هستند؛ این زمان فقط برای اجرای تحلیل پیرامون بازگشایی آمریکا انتخاب شده است. زمان‌بندی وقتی کار می‌کند که Node، تب مرورگر و لپ‌تاپ بیدار باشند. روزهای تعطیل رسمی بازار در تقویم زمان‌بند هنوز لحاظ نشده‌اند.

## ورود Paper (فقط مجازی)

با روشن‌کردن گزینهٔ Paper در داشبورد، فقط اگر همهٔ فیلترهای ورود هم‌زمان تأیید شوند، یک موقعیت مجازی باز می‌شود: روند، شکست کانال یا واکنش Fib، فشار taker، دفتر سفارش، بنیادی CoinGecko و خبر تازهٔ هم‌جهت. هر ۳۰ ثانیه حد ضرر/حد سود موقعیت‌های مجازی بررسی می‌شوند. سقف ریسک باز سبد ۳٪ سرمایهٔ فرضی و exposure حداکثر ۹۵٪ است؛ فایل ثبت در `data/paper-trades.json` محلی و خارج از Git است. هیچ کلید سفارش Binance، پول واقعی یا سفارش واقعی استفاده نمی‌شود. Paper با Binance فعال می‌شود، نه دادهٔ Demo.

### خبر زنده (برای تأیید ورود لازم است)

برای تیترها و رأی خبر CryptoPanic، API token شخصی بگیر و پیش از اجرا در همان CMD تنظیم کن:

```bat
set CRYPTOPANIC_API_KEY=توکن_خودت
npm start
```

توکن را در صفحه، GitHub یا گفتگو وارد نکن. بدون خبر تازهٔ هم‌جهت، موتور ورود را تأیید نمی‌کند و Paper معامله‌ای باز نمی‌کند. CoinGecko ممکن است محدودیت نرخ داشته باشد؛ اگر دادهٔ بنیادی برای نمادی موجود نباشد آن را حدس نمی‌زنیم و ورود تأیید نمی‌شود.

## معیارها و بک‌تست

- فهرست BTC + ده جفت دیگر با بالاترین Quote Volume ۲۴ساعته از Binance؛ stablecoinها و توکن‌های اهرمی فیلتر می‌شوند.
- تحلیل تکنیکال: EMA، MACD، RSI، ATR، حمایت/مقاومت.
- شکست کانال ۲۰کندلی و سطح‌های بازگشت Fibonacci در موج ۱۰۰کندلی اخیر.
- فشار بازار: Binance aggregate taker trades، دفتر سفارش محدود ۱۰۰ سطح، و تخمین معامله‌های بزرگ ≥۱۰k/۱۰۰k دلار از ۵۰۰ معاملهٔ آخر. اندازهٔ معامله شناسایی کیف‌پول/هویت نهنگ نیست.
- توکنومیک CoinGecko: رتبه/ارزش بازار، FDV، حجم، عرضهٔ درگردش و تغییرات بازار.
- خبر و رأی احساسات CryptoPanic؛ فقط خبر تازه‌تر از ۲۴ ساعت در تأیید ورود شمرده می‌شود.
- حد ضرر ۱.۵× ATR با محدودیت ۰.۵–۸٪، هدف ۲R و اندازهٔ موقعیت بر پایهٔ ریسک.
- دکمهٔ تحلیل/بک‌تست، تاریخچهٔ ۵۰۰ کندل را برای BTC و ده دارایی پرتراکنش می‌سنجد. مدل تاریخی شامل تکنیکال، Fib/کانال، taker-buy volume داخل کندل، حدها و کارمزد فرضی است.

**محدودیت صریح بک‌تست:** تاریخچهٔ کامل order book، اخبار گذشته و snapshot بنیادی CoinGecko برای همان لحظه‌های تاریخی در منبع عمومی استفاده‌شده موجود نیست. بنابراین این عوامل فقط در تحلیل جاری و ورود مجازی هم‌زمان اعمال می‌شوند و در بک‌تست تاریخی ادعای بازسازی نمی‌شوند؛ استفاده از مقدار امروز برای تاریخچه باعث look-ahead bias می‌شد. کارمزد بک‌تست ۰.۱٪ هر سمت است؛ لغزش، funding و اثر بازار مدل نشده‌اند.

## ربات انتشار ویدیو در اینستاگرام

ماژول مستقل `instagram-uploader/` ویدیوهای یک پوشه را با کپشن‌شان به‌صورت ریلز در پیج اینستاگرام منتشر می‌کند (API رسمی، بدون لاگین با رمز/کوکی).

```bash
cd instagram-uploader
cp .env.example .env        # IG_USER_ID، IG_ACCESS_TOKEN، IG_PUBLIC_BASE_URL
node cli.js check           # بررسی توکن، سهمیه و دسترسی عمومی فایل
node cli.js list            # ویدیوها و کپشن هرکدام
node cli.js post --dry-run  # شبیه‌سازی
node cli.js watch --archive # رصد مداوم پوشهٔ media/ و انتشار خودکار
```

کپشن از `media/captions.json`، سپس فایل کنار ویدیو (`clip1.txt`)، سپس `IG_DEFAULT_CAPTION` خوانده می‌شود. راهنمای کامل: [instagram-uploader/README.md](instagram-uploader/README.md).

## اجزای پروژه

- `src/providers.js`: Binance، CoinGecko، CryptoPanic و Demo.
- `src/analysis.js`: تکنیکال، فیبوناچی، کانال، orderflow، توکنومیک و فیلتر خبر.
- `src/backtest.js`: مدل تاریخی چندعاملی با حد پویا.
- `src/paper.js`: ثبت و مانیتور معاملات مجازی.
- `src/market-clock.js`: تبدیل ۰۹:۳۰ نیویورک به زمان ایران با لحاظ DST.
- `server.js`: API محلی؛ `public/`: رابط RTL.
- `instagram-uploader/`: ربات انتشار ریلز اینستاگرام از روی پوشهٔ ویدیوها (CLI مستقل، بدون وابستگی npm).

## هشدار

این پروژه توصیهٔ مالی نیست. نتایج بک‌تست سود آینده را تضمین نمی‌کنند، سیگنال و حد ضرر ممکن است خطا کنند و gap/slippage می‌تواند زیان را از ریسک هدف بیشتر کند. این نسخه عمداً سفارش واقعی نمی‌فرستد. برای اجرای واقعی، آداپتر صرافی، مدیریت امن کلیدها، توقف اضطراری و آزمون امنیتی مستقل لازم است.
