# دستیار هوشمند Microsoft Excel 2024 (Excel AI Assistant)

یک دستیار هوشمند واقعی و قدرتمند به زبان فارسی که مستقیماً به **Microsoft Excel 2024** متصل شده و دستورات کاربر به زبان فارسی محاوره‌ای را تجزیه، تحلیل و روی فایل‌های اکسل اجرا می‌کند.

---

## 🌟 قابلیت‌های اصلی سیستم

### ۱. اتصال پایدار به Excel 2024 در ویندوز
- اتصال مستقیم زنده به نرم‌افزار در حال اجرای Microsoft Excel (از طریق COM و `xlwings`).
- پشتیبانی از چند فایل و شناسایی فایل فعال.
- شناسایی خودکار تمام Sheetها، تغییر Sheet فعال و افزودن Sheetهای جدید.
- شناسایی دقیق محدوده استفاده‌شده (`UsedRange`)، هدرها، سطرها و ستون‌ها.
- موتور ذخیره‌سازی، خواندن و نوشتن مستقیم فرمول‌ها و مقادیر.
- درایور دوم مستقل (`OpenPyXL`) برای اجرا در محیط‌های لینوکس و آزمون‌های خودکار با همان اینترفیس.

### ۲. درک عمیق زبان فارسی (Persian NLP)
- درک دستورات محاوره‌ای و متن طبیعی فارسی بدون نیاز به فرمت خشک.
- استانداردسازی ارقام فارسی (۰-۹ به 0-9)، نیم‌فاصله‌ها، حروف مشابه (ی/ي، ک/ك).
- شناسایی ستون‌ها هم از طریق حروف انگلیسی (A, B, C...) و هم نام عنوان ستون (هدر).
- موتور ترکیبی: قوانین معنایی قطعی آفلاین + قابلیت اتصال به APIهای LLM (مانند OpenAI/Azure).

### ۳. محاسبات و فرمول‌نویسی هوشمند
- **چهار عمل اصلی**: ضرب، جمع، تفریق و تقسیم ستون‌ها با درج خودکار فرمول‌های اکسل (مانند `=A2*B2`).
- **توابع آماری**: میانگین (`AVERAGE`)، مجموع (`SUM`)، میانه (`MEDIAN`)، بیشترین (`MAX`)، کمترین (`MIN`)، شمارش داده‌ها (`COUNT`).
- درج خودکار نتایج در پایین ستون‌ها همراه با عنوان فارسی و پررنگ‌سازی (Bold).

### ۴. مدیریت و پالایش داده‌ها
- **حذف ردیف‌های خالی** بدون به‌هم‌ریختن ساختار داده‌ها.
- **حذف داده‌های تکراری** با حفظ رکورد اولیه.
- **مرتب‌سازی (Sort)** بر اساس ستون دلخواه به صورت صعودی یا نزولی (بیشترین به کمترین).
- ایجاد جدول رسمی اکسل (`ListObject`) و فعال‌سازی خودکار فیلترها.

### ۵. قالب‌بندی و هایلایت بصری
- **قالب‌بندی شرطی**: رنگ‌آمیزی سلول‌های بیشتر یا کمتر از یک عدد به رنگ دلخواه (سبز، قرمز، زرد و ...).
- **هایلایت داده‌های تکراری**: شناسایی سریع و تغییر رنگ سلول‌های تکراری به زرد یا رنگ درخواستی.
- **تنظیم خودکار عرض ستون‌ها** (AutoFit) متناسب با طول داده‌ها.
- تنظیم فونت، اندازه و پررنگ (Bold) کردن سلول‌ها.

### ۶. تحلیل هوشمند ساختار فایل (Smart Analysis)
- بررسی کامل ساختار فایل و Sheetها.
- تشخیص نوع داده هر ستون (عددی، متنی، تاریخ، مالی، درصدی، بولی).
- شناسایی فرمول‌های فعال و خطاهای اکسل مانند `#DIV/0!`, `#VALUE!`, `#REF!`, `#N/A`.
- تولید پیشنهادهای کاربردی به زبان فارسی برای بهبود فایل.

### ۷. امنیت، پشتیبان‌گیری و بازگردانی (Undo)
- سیستم تاریخچه تراکنش‌ها و قابلیت لغو آخرین عملیات (`Undo`).
- اخذ تأییدیه امنیتی قبل از اجرای عملیات‌های حساس یا مخرب (مانند حذف سطرها یا تکراری‌ها).
- تهیه نسخه پشتیبان (Snapshot) قبل از هر تغییر ساختاری.

### ۸. رابط‌های کاربری چندگانه
- **رابط گرافیکی دسکتاپ (PySide6 GUI)** با چیدمان راست‌به‌چپ (RTL)، تم تاریک مدرن، پنجره چت، دکمه‌های سریع و وضعیت زنده اکسل.
- **رابط تحت وب (Web Live Preview)** برای مشاهده بلادرنگ شیت و گفتگو با هوش مصنوعی در پورت `8080`.
- **رابط خط فرمان تعاملی (CLI)** برای محیط‌های متنی و اسکریپت‌ها.

## 🚀 نحوه نصب و اجرا

### پیش‌نیازها
- Python 3.10 یا بالاتر
- Microsoft Excel 2024 (برای حالت زنده در ویندوز)

### نصب بسته‌ها
```bash
pip install -r requirements.txt
```

### نحوه اجرا

#### ۱. اجرای رابط گرافیکی دسکتاپ (PySide6 GUI):
```bash
python -m excel_assistant.main --gui
```

#### ۲. اجرای رابط تعاملی وب (پیش‌نمایش در مرورگر):
```bash
python -m excel_assistant.main --web --port 8080
```
سپس مرورگر خود را در آدرس `http://localhost:8080` باز کنید.

#### ۳. اجرای رابط خط فرمان (CLI):
```bash
python -m excel_assistant.main --cli
```
