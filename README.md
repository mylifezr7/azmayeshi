# بازارنگر | تحلیل و بک‌تست رمزارز

پروژهٔ محلی فارسی برای تحلیل BTC به‌علاوهٔ ۱۰ جفت USDT برتر بر اساس حجم ۲۴ساعتهٔ Binance. این نسخه تحلیل و بک‌تست می‌کند و **هیچ سفارش واقعی ارسال نمی‌کند**.

## اجرا در Windows

Node.js نسخهٔ ۱۸ یا جدیدتر را نصب کن. سپس در CMD:

```bat
cd C:\Users\hp\trading_platform2
npm start
```

در مرورگر `http://localhost:3000` را باز کن. برای دادهٔ واقعی اینترنت لازم است. حالت Binance از API عمومی و بدون کلید استفاده می‌کند؛ حالت دمو مصنوعی است و رتبهٔ واقعی حجم را نشان نمی‌دهد.

### تحلیل روزانه در ساعت ۳

زمان پیش‌فرض ۰۳:۰۰ ساعت محلی دستگاه است و در داشبورد قابل تغییر است. در آن زمان تحلیل جاری و بک‌تست ۱۱ نماد اجرا می‌شود، **فقط اگر تب مرورگر و سرور باز باشند و لپ‌تاپ از Sleep خارج باشد**. اگر منظورت ۳ بعدازظهر است، زمان را روی ۱۵:۰۰ بگذار. رمزارزها ۲۴/۷ معامله می‌شوند؛ این برنامه‌بندی فقط زمان اجرای تحلیل است.

### خبر زنده (اختیاری)

برای منبع خبر، API token شخصی CryptoPanic لازم است. در همان پنجرهٔ CMD، پیش از `npm start`:

```bat
set CRYPTOPANIC_API_KEY=توکن_خودت
npm start
```

توکن را داخل صفحه، GitHub یا گفتگو قرار نده. CoinGecko برای اطلاعات بنیادی نیاز به توکن ندارد، ولی نرخ درخواست رایگان محدود است.

## قابلیت‌ها

- دریافت BTC و ۱۰ جفت دیگر با بیشترین **Quote Volume ۲۴ساعته** از Binance؛ stablecoinها و توکن‌های اهرمی فیلتر می‌شوند.
- تحلیل تکنیکال EMA، MACD، RSI، ATR، حمایت و مقاومت.
- فشار خریدوفروش از taker trades اخیر Binance، عدم‌تعادل snapshot دفتر سفارش و فشار taker تاریخی کندل.
- تخمین معامله‌های درشت (≥۱۰هزار و ≥۱۰۰هزار دلار) از ۵۰۰ aggregate trade اخیر؛ این به معنی شناسایی هویت نهنگ یا کیف‌پول نیست.
- اطلاعات بنیادی/توکنومیک از CoinGecko: رتبه و ارزش بازار، FDV، حجم، عرضهٔ درگردش و تغییرات ۷/۳۰روزه.
- تیترهای خبر و رأی احساسات از CryptoPanic در صورت تنظیم کلید.
- نقطهٔ مرجع، حد ضرر پویا ۱.۵× ATR، حد سود ۲R و اندازهٔ موقعیت بر اساس درصد ریسک انتخابی.
- بک‌تست یک مدل امتیازدهی چندعاملی روی تاریخچهٔ ۵۰۰ کندل برای BTC + ۱۰ نماد پرتراکنش؛ گزارش بازده، افت سرمایه، نرخ برد، ضریب سود و تعداد معاملات.
- برنامهٔ اجرای روزانه در ساعت محلی انتخاب‌شده. تا وقتی مرورگر/Node بسته یا لپ‌تاپ Sleep باشد اجرا نمی‌شود؛ برای زمان‌بندی تضمینی باید سرور همیشه‌روشن نصب شود.

## محدودیت‌های بک‌تست و داده

Binance کندل تاریخی و taker-buy volume را می‌دهد؛ فشار کندلی در آزمون تاریخی تقریب می‌شود. تاریخچهٔ کامل order book، دادهٔ تاریخی CoinGecko fundamentals و خبرهای قدیمی در این نسخه وجود ندارد، بنابراین آن سه منبع فقط در تحلیل جاری می‌آیند و داخل آزمون تاریخی قابل بازسازی نیستند. به‌کاربردن دادهٔ بنیادی امروز برای سیگنال‌های سال قبل باعث look-ahead bias می‌شد و عمداً انجام نشده است. هزینهٔ فرضی معامله ۰.۱٪ در هر سمت است؛ لغزش، funding، تأخیر و اثر بازار مدل نشده‌اند.

## اجزای پروژه

- `src/providers.js`: Binance public API، CoinGecko، CryptoPanic و دادهٔ دمو.
- `src/analysis.js`: اندیکاتور، عوامل فشار/عرضه و طرح ریسک.
- `src/backtest.js`: شبیه‌ساز تاریخی و حدهای پویا.
- `server.js`: API محلی و اجرای سبد ۱۱ رمزارز.
- `public/`: داشبورد فارسی راست‌به‌چپ.

## هشدار

این ابزار توصیهٔ سرمایه‌گذاری نیست. امتیازها احتمال موفقیت را نشان نمی‌دهند. نتیجهٔ بک‌تست تضمین‌کنندهٔ آینده نیست و سیگنال/حد ضرر ممکن است نادرست باشد. حد ضرر تضمین نمی‌کند زیان به مقدار انتخاب‌شده محدود بماند. سفارش واقعی و معاملهٔ خودکار در این پروژه وجود ندارد.
