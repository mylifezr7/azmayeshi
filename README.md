# نُوا | آزمایشگاه استراتژی

MVP فارسی و راست‌به‌چپ برای ساخت و ارزیابی ستاپ‌های معاملاتی. موتور اجرا، الگوریتم استراتژی و آداپترهای داده از هم جدا هستند.

## اجرا

نیاز به Node.js 18 یا بالاتر؛ بدون وابستگی npm:

```bash
npm start
# http://localhost:3000
npm test
```

## قابلیت‌های پیاده‌سازی‌شده

- **مغز تحلیل بازار:** تحلیل قاعده‌محور چندلایه با EMA، مومنتوم، اجماع سیگنال استراتژی‌ها، ATR و برآورد ریسک/نقدشوندگی. امتیاز خروجی «قدرت اکتشافی» است، نه احتمال موفقیت.
- **چند استراتژی:** سه نمونهٔ آموزشی EMA Cross، RSI Reversal و Channel Breakout؛ انتخاب یکی برای بک‌تست، و ترکیب سیگنال‌ها برای تحلیل اجماع.
- **ثبت عملکرد گذشته:** نتایج بک‌تست در `data/learning.json` ذخیره و میانگین‌های اخیر برای مقایسهٔ ستاپ‌ها نمایش داده می‌شوند. این آمار ساده است؛ **مدل یادگیری ماشین آموزش داده نمی‌شود**.
- **مدیریت ریسک:** ریسک اسمی معامله، کاهش خودکار ریسک در شرایط نوسان بالا/نقدشوندگی پایین، اندازه موقعیت بر مبنای فاصله حد ضرر.
- **نقدشوندگی و نهنگ‌ها:** برآورد تقریبی حجم و دامنه کندل ارائه می‌شود؛ دادهٔ واقعی دفتر سفارش، جریان سفارش یا تشخیص نهنگ متصل نیست.
- **اخبار و احساسات:** بخش نمایش وضعیت اتصال دارد، اما خوراک خبر/شبکه اجتماعی وصل نیست؛ امتیاز خنثی پیش‌فرض، تحلیل احساسات واقعی نیست.
- **اسکن نمادها:** ارزیابی اکتشافی شش نماد BTC، ETH، SOL، BNB، XRP و ADA با منبع دادهٔ انتخاب‌شده.
- **حد سود/ضرر پویا:** حد ضرر بر پایه ATR تقریبی و محدود به ۰.۵٪ تا ۵٪، حد سود ۲R؛ اگر هر دو سطح در یک کندل لمس شوند، فرض محافظه‌کارانهٔ «حد ضرر اول» اعمال می‌شود.
- **بک‌تست و اجرای آزمایشی:** گزارش عملکرد، نمودار، جدول معاملات و نشست Paper Trading قابل توقف. اجرای آزمایشی فعلاً به بازار زنده وصل نیست.
- **داشبورد و مدیریت:** انتخاب نماد/ریسک/منبع، گزارش چندلایه، پنل افزودن ستاپ، اسکن و جست‌وجوی شبکه‌ای پارامترهای استراتژی.
- **بهینه‌سازی:** جست‌وجوی شبکه‌ای پارامترها و رتبه‌بندی بر اساس بازده/افت سرمایه؛ نتیجه روی همان بازه مستعد بیش‌برازش است و صرفاً نقطه شروع برای آزمون خارج از نمونه است.

## معماری

- `src/strategies.js`: تعریف و اعتبارسنجی استراتژی‌ها. افزودن نوع جدید نیازمند افزودن قواعد سیگنال در `src/backtest.js` و مجازکردن نوع در ثبت‌کننده استراتژی است. ستاپ‌های سفارشی از پنل در `src/custom-strategies.json` ذخیره می‌شوند.
- `src/providers.js`: قرارداد `getCandles({ symbol, timeframe, limit })`. آداپترهای داده مصنوعی و کندل عمومی Binance آماده‌اند؛ Soft4FX/CSV نقطه اتصال معماری است ولی هنوز کدنویسی نشده.
- `src/backtest.js`: اندیکاتورها، تولید سیگنال، اندازه موقعیت، حدهای پویا و معیارهای عملکرد.
- `src/intelligence.js`: تحلیل چندلایه، اجماع، مومنتوم، ATR و برآوردهای نقدشوندگی.
- `src/optimizer.js`: جست‌وجوی شبکه‌ای پارامترها.
- `src/learning.js`: ثبت آماری بک‌تست‌های اجراشده در `data/learning.json` (دادهٔ محلی نادیده‌گرفته‌شده در Git).
- `server.js`: REST API و لایهٔ HTTP؛ `public/`: رابط RTL.

## APIهای اصلی

`GET /api/strategies`, `GET /api/intelligence?symbol=BTCUSDT`, `GET /api/learning`, `POST /api/backtest`, `POST /api/scan`, `POST /api/optimize`, `POST /api/paper/start`, `POST /api/paper/stop`.

## ریسک و محدودیت‌های مهم

این پروژه توصیه سرمایه‌گذاری نیست. ستاپ‌های موجود فقط نمونه‌های آموزشی‌اند و «سودده» یا بهینه‌سازی‌شده نیستند؛ هیچ سودی تضمین نمی‌شود. منبع آزمایشی دادهٔ مصنوعی تولید می‌کند، نه تاریخچهٔ بازار. Binance برای کندل عمومی در نظر گرفته شده است؛ اتصال ممکن است به‌دلیل شبکه/دسترس‌پذیری سرویس شکست بخورد. پیاده‌سازی کارمزد را ساده‌سازی می‌کند و اسپرد واقعی، لغزش، تأخیر، تأمین مالی، کیفیت داده و جزئیات اجرای کارگزار را مدل نمی‌کند. شکاف قیمت می‌تواند زیان واقعی را از ریسک هدف بیشتر کند.

**برای حساب زنده/سرمایه واقعی مناسب نیست.** آداپتر کارگزار/MT5، احراز هویت امن، مدیریت خطا و قطع اتصال، قواعد حداقل حجم و tick size، توقف اضطراری، ثبت رخداد، کنترل ریسک سمت سرور و بازبینی امنیتی هنوز پیاده‌سازی نشده‌اند. MetaTrader یا Soft4FX در این نسخه وصل نیستند. کلید API را در کد یا مرورگر قرار ندهید.
