منابع داده

اتصال به دادهٔ بنیادی و قیمت

پروژه به‌طور پیش‌فرض امن و آفلاین در حالت دمو اجرا می‌شود. دادهٔ واقعی با کلید API شخصی و از سمت سرور قابل فعال‌سازی است.

۱در Finnhub یک API token تهیه کن.
۲در CMD پیش از اجرا بنویس:set FINNHUB_API_KEY=توکن_خودت
۳همان پنجره را باز نگه‌دار و `npm start` را اجرا کن؛ سپس منبع Finnhub را انتخاب کن.
توکن را در صفحهٔ وب، GitHub یا چت قرار نده. دسترسی رایگان API محدود است و ممکن است بعضی داده‌ها با تأخیر یا محدودیت برگردند.
هشدار مهم

این نرم‌افزار فقط ابزار تحلیلی/آموزشی است و توصیهٔ سرمایه‌گذاری نیست. سیگنال، نقطه ورود، نسبت ریسک و برچسب احساسات ممکن است نادرست باشند. دادهٔ دمو ساختگی است. تخمین فشار معاملات از OHLCV، جایگزین order book یا tape واقعی نیست. ساعات نیویورک با DST محاسبه می‌شوند اما تعطیلات رسمی بورس لحاظ نشده‌اند. هیچ معامله یا سفارش خودکاری انجام نمی‌شود؛ قبل از هر تصمیم داده را از منبع معتبر مستقلاً تأیید کن.
