منابع و زمان‌بندی

Binance · CoinGecko · CryptoPanic

قیمت و حجم از API عمومی Binance؛ توکنومیک از CoinGecko؛ خبر اختیاری از CryptoPanic.

۱Binance عمومی برای قیمت، کندل، دفتر سفارش و جریان معاملات نیاز به API key ندارد.
۲CoinGecko ممکن است محدودیت نرخ داشته باشد؛ مقادیر فاندامنتالِ خالی را صفر فرض نکن.
۳برای خبر، در CMD بنویس:set CRYPTOPANIC_API_KEY=توکن_خودت
زمان ۰۳:۰۰ بر مبنای ساعت محلی مرورگر است. برای اجرای خودکار، تب داشبورد و سرور باید روشن بمانند؛ لپ‌تاپ در Sleep کار را متوقف می‌کند.
هشدار ریسک

این نرم‌افزار توصیه سرمایه‌گذاری نیست. تحلیل چندعاملی و بک‌تست تضمین‌کنندهٔ سود آینده نیستند. بخش order book فقط snapshot محدود و جریان taker فقط ۵۰۰ معاملهٔ آخر است؛ شمارش معاملات بزرگ معیار قطعی فعالیت نهنگ نیست. کارمزد فرضی بک‌تست ۰.۱٪ هر سمت است؛ لغزش، فاندینگ، تأخیر و اثر بازار مدل نشده‌اند. هیچ سفارش واقعی یا معاملهٔ خودکار ارسال نمی‌شود.
